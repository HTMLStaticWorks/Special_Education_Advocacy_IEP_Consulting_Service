# Guided Path Advocacy — Special Education Advocacy & IEP Consulting Website Template

A professional, agency-quality HTML5 website template for a Special Education Advocacy & IEP Consulting service (**"Guided Path Advocacy"**).

## Brand Tagline
> **"Clear Guidance. Stronger Educational Support."**

---

## 🌟 Key Features

- **Theme Engine**: Real-time Light & Dark mode toggle with `localStorage` persistence and automatic OS system preference detection.
- **Editorial Design System**: Custom HSL/HEX color palette (Warm Ivory `#FAF7F2`, Muted Teal `#2A7B88`, Sage Green `#5B8266`, Soft Coral `#D96B43`, Deep Navy `#1C2833`).
- **Typography**: Dual Google Font combination (`DM Serif Display` / `Lora` for headings, `Manrope` / `Inter` for body text).
- **Mandatory Navigation Structure**:
  - Logo | Home ▾ (Home, Home 2) | Services ▾ (IEP Review, IEP Meeting Support, Evaluation Guidance, Advocacy Consultation, Parent Preparation, Service Details) | Resources | About | Insights | Contact | Theme Toggle | Login | Sign Up | Get Support
- **Interactive UI Capabilities**:
  - Live JavaScript search & category filtering on `resources.html` and `insights.html`.
  - Accessible Bootstrap 5 FAQ accordions.
  - Interactive front-end form validation on `contact.html`, `login.html`, `signup.html`, and `forgot-password.html`.
  - Password visibility toggles.
  - GSAP entrance scroll reveal animations.
  - Back-to-top button.
- **Responsive Layout**: Thoroughly tested across mobile (320px - 425px), tablet (768px - 1024px), and desktop (1280px - 2560px+) viewports.
- **Disclaimers & Ethics**: Clear legal and medical disclaimers explicitly framing services as educational consulting and advocacy support (not legal or medical advice).
