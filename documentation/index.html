1. Template Overview

Guided Path Advocacy is a premium, agency-grade HTML5 template designed for Special Education Advocacy practices, IEP consultants, parent education specialists, and educational advisors.

3. Color System & Theme Customization

The site uses CSS variables defined in assets/css/style.css for automatic Light / Dark mode switching:

Variable Name Light Theme Value Dark Theme Value Usage
--bg-primary #FAF7F2 (Warm Ivory) #111823 Main Page Background
--color-primary #2A7B88 (Muted Teal) #389BA8 Primary Brand Accent & Buttons
--color-secondary #5B8266 (Sage Green) #749F80 Secondary Accent & Badges
--color-accent #D96B43 (Soft Coral) #E87A5D Highlight Calls to Action

4. Theme Switcher & JS Modules

The Theme Switcher automatically respects the user's OS preference (`prefers-color-scheme: dark`) on first load and persists manual choices to localStorage under the key gpa_theme.
